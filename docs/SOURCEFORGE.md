**Project name**

    Frametide OS

**Summary** (max. 70 characters)

    Gaming Linux that just works: drivers, RGB & fans, no terminal

**Description**

    Frametide OS is a Linux distribution for gamers, creators and developers who are
    leaving Windows. It is based on Ubuntu 26.04 LTS (5 years of updates) with GNOME 50.

    • Zero-touch drivers: NVIDIA, AMD and Intel are set up on first boot – Secure Boot included
    • Frametide Center: updates, GPU drivers, RGB lighting and fan curves in one app
    • Game check: does a game run on Linux? ProtonDB rating and anti-cheat status
    • Move from Windows: files, bookmarks, Wi-Fi and Steam games come along
    • Frametide Store: 95 curated apps, all of Flathub and one-click dev environments
    • Pre-installed: Steam, Proton, ArtCraft office suite, GitHub Desktop; Chrome and VS Code on first boot
    • Tuned for low latency: ntsync, zram, optimized I/O, no Snap, no telemetry
    • 10 languages offline

    Status: alpha – please test in a VM first.
    Source code, issues and roadmap: https://github.com/ChopstickGuy/frametide-os
